🛡️ PhishGuard

A cybersecurity awareness project designed to help users assess suspicious URLs and QR codes before interacting with them.

📌 About the Project

PhishGuard is a web-based security assessment tool that analyzes URLs and identifies common suspicious patterns associated with potentially unsafe links.

It also provides a QR scanning feature to help users inspect QR-code destinations before opening them.

✨ Features

- 🔗 URL security analysis
- 📊 Risk score calculation
- 🟢 Low Risk / 🟠 Suspicious / 🔴 High Risk classification
- 🔐 HTTPS detection
- ⚠️ Suspicious keyword detection
- 🌐 IP-address detection
- @ symbol detection
- 📏 URL length analysis
- 🔗 URL shortener detection
- 📷 QR code scanning
- 📱 Responsive web interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 QR Code library

🎯 Objective

The main objective of PhishGuard is to improve cybersecurity awareness by helping users examine suspicious links before visiting them.

⚠️ Disclaimer

PhishGuard provides a risk assessment based on predefined security indicators. It is an educational cybersecurity project and does not guarantee that a website is completely safe or malicious.

🚀 Future Enhancements

- Integration with real-time threat intelligence databases
- Improved phishing detection
- Domain reputation checking
- More advanced QR-code analysis
- Security reporting and history
